# 퍼먼트 커피랩 (Ferment Coffee Lab)

지역 특산물 발효 기반 생두 향미 재설계·표준화 기술 브랜드 소개 사이트.
Next.js 16 (App Router) + React 19 반응형 인터랙티브 원페이지.

## 실행

```bash
npm install
npm run dev        # http://localhost:3000
npm run build && npm start
```

## 배포

Vercel에 그대로 올리면 됩니다. 정적 호스팅이 필요하면 `next.config.mjs`에
`output: "export"`를 추가하고 빌드 후 생성되는 `out/` 폴더를 올리세요.

## 디자인 방향

아이보리 바탕(#faf7f1) + 볼드 산세리프 제목 + 브랜드 레드(#be2e2e).
삼양식품 홈페이지처럼 섹션 제목을 가운데 정렬한 기업 소개 톤입니다.
원형 로고·워드마크·섹션 번호·영문 라벨·모노 캡션을 모두 걷어냈습니다. 레드·골드·로즈는
지역 에디션 패키지 사진에서 직접 추출한 색입니다. 상단은 3장짜리 슬라이더,
마지막은 대표 연락처를 담은 온라인 명함 블록입니다.

## 폰트

**Wanted Sans Variable** 한 종만 씁니다. 제목 700, 본문 400. 모노스페이스
캡션과 영문 소문자 라벨은 전부 걷어냈고, 화면에서 가장 작은 글자도 13px입니다.

## SEO / GEO

배포 도메인은 `lib/site.js`의 `SITE_URL` 한 줄에서 나온다. Vercel에서는
`NEXT_PUBLIC_SITE_URL` 환경변수로 덮어쓸 수 있고, 메타데이터·사이트맵·
구조화 데이터·정규 URL이 전부 그 값을 따라간다.

- **메타데이터** (`app/layout.jsx`) — 제목 템플릿, 설명, 키워드, 정규 URL,
  로봇 지시(`max-image-preview:large`), Open Graph, 트위터 카드.
  서치콘솔·네이버 소유 확인 코드는 파일 안 주석 자리에 넣으면 된다.
- **구조화 데이터** (`app/Schema.jsx`) — `@graph` 하나에 Organization/Brand,
  WebSite, WebPage(+BreadcrumbList), FAQPage, HowTo(발효 6단계),
  ItemList(제품·향미), WebApplication(취향 테스트)을 담고 `@id`로 연결한다.
- **`app/sitemap.js` · `app/robots.js`** — `/sitemap.xml`, `/robots.txt` 자동
  생성. 로봇 파일은 GPTBot·ClaudeBot·PerplexityBot·Yeti 등 생성형 검색
  크롤러를 이름으로 허용한다.
- **`public/llms.txt`** — AI가 읽고 인용할 브랜드 요약. 기술·공정·향미·검증
  수치와 함께 "가향 커피와 다르다", "가격은 아직 비공개" 같은 인용 주의사항을
  적어 잘못된 요약을 줄인다.
- **FAQ 섹션** — 답변 한 문단이 질문 하나에 대해 독립적으로 완결되게 써서,
  검색 스니펫과 AI 답변에 그대로 실려도 문맥이 끊기지 않는다. 화면과
  FAQPage 스키마가 같은 원본(`lib/content.js`의 `FAQ`)을 쓴다.
- 문서에 `<h1>`은 하나(첫 히어로 슬라이드)뿐이고, 나머지 슬라이드 제목은
  같은 모양의 문단이다.

## 커피 취향 매칭 테스트 (팝업)

10문항 · 4축 · 6산지 × 4가공 × 8품종. 사이트 어디서나 팝업으로 뜬다.

- **질문·채점·매핑**: `lib/quiz.js` 한 파일. A/B 응답을 산미·바디감·단맛·개성
  네 축에 누적하면서 산지·가공·품종에 표를 던지고, 축 임계값 캐스케이드로
  최종 유형을 정한다.
- **임계값 검증**: `npm run verify:quiz` — 1,024가지(2^10) 응답 조합을 전수
  계산해 유형·산지·가공·품종 분포를 출력한다. 여섯 유형이 10~26%,
  여덟 품종이 6~26%로 모두 도달 가능하다.
- **팝업**: `components/CoffeeTest.jsx`. 데스크톱은 가운데 카드, 900px
  이하는 화면을 꽉 채우는 시트. 열려 있는 동안 body 스크롤을 잠그고
  스크롤바 폭 변화를 padding으로 메운다. Esc·배경 클릭·뒤로가기로 닫히고
  Tab은 팝업 안에서만 돈다.
- **여는 곳**: 헤더 CTA, 히어로 4번째 슬라이드, 취향 테스트 섹션 버튼,
  모바일 하단 고정 바. 전부 `components/TestLauncher.jsx`의 커스텀 이벤트를
  던지므로 `app/page.jsx`는 서버 컴포넌트로 남는다.
- 응답은 브라우저 안에서만 계산되고 저장·전송되지 않는다.

## 특징

- **문서 이미지 없음.** 원본 HWP의 표·인포그래픽(공정도, 밸류체인, 시장 규모,
  TAM/SAM/SOM, 관능 레이더, 로드맵)은 전부 HTML·SVG로 다시 그렸습니다.
  사진(실험실, 과실, 패키지, 블라인드 테스트)만 원본에서 크롭해 webp로 씁니다.
- **히어로 슬라이더.** 브랜드 메시지 / 지역 한정판 / 블라인드 테스트 3장이
  6.5초마다 자동 전환됩니다.
- **온라인 명함.** 대표 성명·전화·이메일·소재지를 담은 카드. 전화/이메일은
  모바일에서 바로 연결됩니다.
- **인터랙션.** 발효 공정 6단계 스테퍼, 향미 라인업 탭, 스크롤 등장,
  카운트업, 차트 애니메이션, 스크롤 진행바, 현재 섹션 표시 내비, 모바일 드로어.
- **고정 스크롤 스테퍼(모바일).** 공정 6단계와 향미 3종은 화면에 고정된 채
  세로 스크롤만으로 내용이 바뀝니다. `.pin__stage`가 `position: sticky`로
  붙고, 바깥 래퍼의 남은 높이(단계 수 x `--adv`)를 스크롤이 소비하면서 그
  진행률이 그대로 단계 인덱스가 됩니다. 상단에 `01 / 06` 카운터와 진행 막대를
  두고, 첫 단계에서만 "스크롤" 힌트를 띄웁니다. 진행 막대(공정)와 탭(향미)을
  누르면 해당 단계 위치로 부드럽게 이동합니다. 래퍼에 여분 높이가 없는
  데스크톱에서는 pin이 자동으로 꺼지고 기존처럼 클릭·호버로 전환됩니다.
  계산식은 `components/usePin.js` 한 곳에 있습니다.
- **전면 사진 밴드.** 삼양식품 홈페이지처럼 섹션과 섹션 사이를 화면 폭
  전체 사진으로 끊는다(`components/Band.jsx`). 사진 위에 이중 그라디언트를
  깔아 어떤 사진이 와도 글자 대비가 확보된다. 문구는 `lib/content.js`의
  `BANDS`.
- **제품 카드.** 색 타일 위에 제품 사진을 얹는 구성. 컷아웃 패키지는
  `fit: "contain"`, 일반 사진은 꽉 채워 자른다. 데스크톱 4열, 폰 2열.
- **모바일.** 360 / 390 / 820 / 1440px에서 가로 스크롤 0 확인.
  히어로 이미지는 화면 폭 전체로 확장되고 좌우 스와이프로 슬라이드가 넘어갑니다.
  하단에 전화·이메일 고정 바가 붙고, 터치 타깃은 48px 이상, 제목 크기는
  모바일 전용 스케일을 씁니다.

## 구조

클라이언트 요청("회사 소개에 가까운 온라인 명함")에 맞춰 6개 섹션으로 압축했습니다.

```
1  HERO      4장 슬라이더 (자동 전환 · 좌우 스와이프 · 화살표)
2  ABOUT     한국의 커피를 찾아서 · 핵심 지표 4 · 지역 상생 5단계
—  BAND      전면 사진 (발효 실험실)
3  PROCESS   발효 공정 6단계 스테퍼
4  FLAVOR    향미 라인업 탭 (딸기 · 포도 · 청사과)
5  TASTE     커피 취향 테스트 안내 · 유형 미리보기 3종 · 팝업 실행
—  BAND      전면 사진 (지역 에디션)
6  PRODUCT   제품 4종(사진 카드) · 지역 에디션 3종
7  RESULTS   블라인드 테스트 · 관능 레이더 · 현장 사진 · 연혁
8  FAQ       자주 묻는 질문 7 (FAQPage 스키마와 같은 원본)
9  CONTACT   온라인 명함 (대표 · 전화 · 이메일 · 소재지)
```

시장 규모 차트, TAM/SAM/SOM, 향미 시뮬레이터, 비즈니스 모델, 상세 로드맵은
IR 자료 성격이라 이번 버전에서 뺐습니다. 컴포넌트 파일(`Why.jsx`, `Design.jsx`,
`Local.jsx`, `Roadmap.jsx`)은 그대로 남겨뒀으니 `app/page.jsx`에 다시 넣으면
바로 살아납니다.

## 수정 가이드

- 문구·수치: `lib/content.js`
- 배포 도메인·메타 설명·키워드·대표 이미지: `lib/site.js`
- 테스트 문항·점수·결과 유형: `lib/quiz.js` (고친 뒤 `npm run verify:quiz`)
- 색·타이포·간격: `app/globals.css` 상단 `:root` 토큰
  - `--paper` 아이보리 바탕, `--red` 브랜드 레드, `--gold` `--rose` 보조색
  - `--berry` `--grape` `--apple` `--citrus` 는 차트·미터 전용 데이터 컬러
- 시뮬레이터 계산식: `components/Design.jsx` 상단 (개념 데모용 근사식)

## 연락처

`lib/content.js`의 `COMPANY` 객체에 대표·전화·이메일·소재지가 들어 있습니다.
수정은 이 한 곳만 고치면 사이트 전체(명함·푸터·버튼)에 반영됩니다.

## 출처

사진·수치는 제공된 HWP 문서(퍼먼트 커피랩 소개서, PSSD 사업계획서)에서
가져왔습니다. 시장 규모는 credence research 인용분입니다.

## 사진

원본 사진은 전부 색보정을 거쳤습니다 (필믹 S커브 · 웜 밸런스 · 채도 +12% ·
언샵 마스크). 지역 에디션 3종은 원본에서 박스를 하나씩 분리해 배경색을 맞춘
제품컷으로 정리했습니다.
